\section{Specific Requirements}

\subsection{External Interface Requirements}
\subsubsection{User Interfaces}
A responsive web application consisting of a Consumer View (featuring live energy gauges, transaction histories, and credit countdown elements) and an Admin View (displaying real-time anomaly warning flags).

\subsubsection{Hardware Interfaces}
\begin{itemize}[leftmargin=*]
    \item ESP32 Microcontroller.
    \item Linear Potentiometer (for analog grid load simulation).
    \item Electromechanical Relay (for circuit line disconnection).  
    \item I2C LCD Display (for localized device status metrics). 
\end{itemize}

\subsubsection{Software Interfaces}
\begin{itemize}[leftmargin=*]
    \item \textbf{Database:} SQLite for quick historical logging.
    \item \textbf{Blockchain Dev-Env:} Hardhat for running localized Solidity testnets.
    \item \textbf{ML Environment:} Scikit-Learn (Python) for execution of regression and Isolation Forest pipelines.
\end{itemize}

\subsubsection{Communication Interfaces}
\begin{itemize}[leftmargin=*]
    \item HTTP REST protocol for ESP32 data ingestion into FastAPI.  
    \item WebSockets for streaming live telemetry updates to the React interface.
    \item JSON-RPC protocol for backend communication with the blockchain ledger via Web3.py. 
\end{itemize}
