\chapter{EXPECTED RESULTS}
The final prototype will deliver an integrated, low-latency physical automated prepaid grid loop. Operating the linear potentiometer will successfully stream smooth multi-variable JSON consumption telemetry to the FastAPI gateway. The system will achieve complete autonomous enforcement: the exact millisecond the smart contract calculates a zero-token balance, it will emit a ledger event prompting the backend to open the physical ESP32 relay, instantly isolating the consumer's load circuit.

On the software layer, the React-native dashboard will display responsive real-time consumption charts alongside a live, machine-learning-driven countdown timer showing exactly how many hours of power remain. Simultaneously, simulated line-tampering or meter-bypassing events will instantly trigger unsupervised anomaly warning flags on the administrative interface.

The framework's final performance will be quantitatively evaluated using four core engineering metrics:
\begin {itemize}

\item Smart Contract Transaction Latency: Time delay between an edge update and ledger balance deduction confirmation.

\item Balance Deduction Accuracy: Mathematical precision of contract-executed tariff calculations versus theoretical values.

\item Predictive Forecasting Error: The accuracy of the budget exhaustion countdown engine, evaluated using Root Mean Squared Error (RMSE).

\item Anomaly Detection Precision: The success rate of the Isolation Forest model in accurately isolating tampering events with minimal false alarms.
\end{itemize}
